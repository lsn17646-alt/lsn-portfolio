# LSN Portfolio

Personal portfolio website of Lv Shuning.

Live Site: https://http://lvshuning.com

This portfolio presents selected works in product design, interaction design, user research, service experience and visual storytelling.

The website is designed as an interactive retro handheld game console experience. Each project is presented like a game cartridge, allowing viewers to explore selected works in a playful and structured way.

For privacy and project confidentiality reasons, this public repository is used as a portfolio entry page. Full project details are available through the live portfolio website or upon request.
